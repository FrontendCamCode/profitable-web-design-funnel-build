# Marketing Copy Exports

This directory contains all the marketing and sales copy from the funnel, extracted into clean, editable Markdown files.

## Files & Source Mapping

| Markdown File | Source HTML Path |
|---------------|------------------|
| `sales.md` | `page-templates/sales/index.html` |
| `checkout.md` | `page-templates/checkout/index.html` |
| `oto.md` | `page-templates/oto/index.html` |
| `oto2.md` | `page-templates/oto2/index.html` |
| `thank-you.md` | `page-templates/thank-you/index.html` |

## How To Use

1. **Edit the Markdown files** - Make your copy changes in the `.md` files in this directory
2. **Copy the updated text** - When you're ready to update the HTML, copy the edited sections from the Markdown
3. **Paste back into HTML** - Locate the corresponding section in the source HTML file and paste your updates

## Notes for Cam

- All user-facing copy has been extracted (headlines, body text, CTAs, form labels, disclaimers, etc.)
- Placeholders like `[INSERT PRODUCT NAME]` have been preserved as-is
- HTML tags, CSS, and JavaScript have been excluded
- The structure uses Markdown headings (##) to organize content by section
- Edit the Markdown files here, then paste changes back into the HTML templates when ready
