# Whop Growth Funnel

A static, responsive long-form sales letter for Lucas’s Whop setup offer. The page mirrors the supplied DaaS funnel’s editorial structure while using original copy based on current Whop Ads, Payments, Network, and developer documentation.

## Commands

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```

## Structure

- `client/index.html` — crawlable long-form page and quiz shell
- `client/src/styles.css` — reference-faithful responsive design system
- `client/src/main.ts` — tabs, floating CTA, and qualification quiz behavior
- `client/public/manus-routes.json` — public route declaration
- `ideas.md` — accepted design direction
- `plan.md` — implementation and validation plan
